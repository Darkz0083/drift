# Code of Conduct

This fork adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be decent. Assume good faith. Critique code, not people. Harassment of
any kind is not welcome here, and maintainers may remove comments, commits or
contributors that make the project worse to be part of.

## Scope

This repository — issues, pull requests, discussions, and any space where someone
is representing the project.

## Reporting

Open an issue asking for a private channel, or contact the maintainer through
GitHub. Reports are read and acted on; they are not published.
